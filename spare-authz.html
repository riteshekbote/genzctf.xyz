3. What a triager should do

  1. Run the five unauthenticated curl commands in section 2 (no tokens, no secrets — every line is read-only).
  2. Watch: two routes return 200 with zero privileges, the other two return 401. That contrast is the bug.

4. Impact (honest)

  • Medium. The middleware evaluates req.headers.authorization != null on /v1/global/*, never its signature/expiry (every other controller does). Results: topology/region disclosure, tenant BOOL oracle, untrusted UAT cross-population statements — all at zero privilege, remotely, read-only.
  • Not raised to High: no PII/business data was demonstrated (organizations list empty at this stage) and write verbs still 401.

5. Remediation

  • Enforce the shared token-validity middleware on every route served by the global controller (same as the rest of the app).
  • Remove the public organization lookup from unauthenticated reach (or rate-limit + scoped authz).
  • Ship the same fix to UAT; retest with randomized junk tokens to confirm 401.
